PASO 1: SELECCIONAR UTXO

Elegir el UTXO que vamos a gastar

Una transacción Bitcoin no empieza indicando simplemente una cantidad. Primero debemos elegir una salida no gastada (UTXO) de una transacción anterior. Para identificarla necesitamos su TXID y el índice de salida (vout).

¿QUÉ ACABAMOS DE SELECCIONAR?

De output anterior a input nuevo

La transacción anterior creó una salida con una cantidad de satoshis y una condición de gasto. Mientras esa salida no se haya gastado, es un UTXO. Nuestra nueva transacción hará referencia a ese UTXO mediante TXID + vout.

TRANSACCIÓN ANTERIOR │ └── OUTPUT #0 │ ├── 0 sats │ └── scriptPubKey │ ▼ UTXO │ │ gastar ▼ NUEVA TRANSACCIÓN │ └── INPUT #0

Como esta primera versión se centra en direcciones bc1q, aceptamos únicamente outputs P2WPKH / SegWit nativo.
